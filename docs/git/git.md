
Do not develop on the ```main``` branch, the ```main``` branch should contain the latest (tested) version. 

### Repository naming 
Naming of the Repository should be ClientName_Function_project_number. Each repository should only contain one controller. <br>
So if a project contains multiple cobots, and each are controlled with their own c++ controller, each controller should be its own repository. 
E.g. Customer1_Palletizer_9999, Customer1_CasePackerLine1_9999, Customer1_CasePackerLine2_9999, and Customer1_Palletizer_1234.
<br>
Adding the project_number is required because of repeating customers, the project_number can be found on the one-drive in the projects folder, each project folder should contain the project_number.
